## 2026-08-03 - Prevent mapping directly inside ScrollView without React.memo\n**Learning:** Mapping directly inside `ScrollView` creates new function instances for handlers (e.g. `onPress`) on every render, which is inefficient. Although for small lists `ScrollView` is fine, components should be extracted and wrapped in `React.memo` to avoid unnecessary re-renders.\n**Action:** Extract list item components and wrap them in `React.memo`, passing necessary props. Use `FlatList` for larger lists.
